About RigBuilder

RigBuilder is an AI-powered PC recommendation system designed to help users find a PC configuration based on their budget and requirements.

What is RigBuilder?

RigBuilder recommends a complete PC configuration based on the user's budget, intended use, upgrade preferences, and other requirements.

How It Works

Users provide their requirements through the PC Builder form. RigBuilder then uses trained machine learning models to recommend suitable PC components.

Machine Learning Models

RigBuilder uses two trained machine learning models to generate alternative PC build recommendations:

  • Random Forest
  • CatBoost

Components Considered

Recommendations can include:

  • CPU
  • GPU
  • Motherboard
  • CPU Cooler
  • RAM
  • Storage
  • PSU
  • Cabinet
  • Monitor

Key Features

  • Budget-based PC recommendations
  • AI-powered component selection
  • Multiple model recommendations
  • Component compatibility checking
  • Save recommended builds to cart
  • Place orders for saved builds

Our Goal

The goal of RigBuilder is to simplify the PC building process and help users make informed configuration decisions without having to manually research every component.
